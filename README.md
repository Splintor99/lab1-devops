# Лабораторна робота №1

Основи DevOps та конфігурації локального середовища.

Виконав: Брошко О. М., група КБ-212.

## Програма

Обчислення площі та периметра прямокутника.

- lib.py — функції обчислення площі та периметра.
- main.py — імпорт функцій, їх виклик і виведення результатів.

## Запуск

Потрібен установлений менеджер uv.

Команда запуску з папки проєкту:

    uv run main.py

Для сторін 5 і 3 площа дорівнює 15, а периметр — 16.
